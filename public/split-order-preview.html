What you're looking at. Hover any card — every copy of the same order glows (same colour stripe = same order). Click ✓ Mark made / ✓ Mark packed to push one item forward and watch it hop columns.
Ready-for-Delivery gate. A packed item whose order still has unpacked items waits in Packing (✓ packed · waiting). The order only moves to Ready when every item is packed — then it lands there as one whole card. One order, one delivery.
View as. Lead / Boss see the ⇄ also in tag (where else the order sits) and can act anywhere. Departments only get the buttons for their own column and don't see the also-in tag — they just work their items.
